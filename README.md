# Justin Fay's Homebrew Tap

Homebrew casks for my macOS apps.

## Tidebar

[Tidebar](https://github.com/JustinFay01/Tidebar) shows your current Dexcom glucose value and trend in the macOS menu bar.

```sh
brew install --cask justinfay01/tap/tidebar
```

Casks here are updated automatically by each app's release script.
